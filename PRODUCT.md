# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Vite + React + Tailwind CSS + Lucide React + Framer Motion

## Users

Profile visitors, recruiters, collaborators, friends, and social media followers seeking personal info and key links.

## Product Purpose

A modern minimalist link-in-bio profile page presenting personal identity, brief bio, and direct links to major social channels (Facebook, TikTok, Gmail, GitHub).

## Positioning

An ultra-clean, distraction-free personal bio with an obsidian dark aesthetic, crisp monochrome typography, and refined violet glow accents, easily customized via a single config file.

## Operating Context

Mobile-first browsing (from social media bio links) and desktop web. Fast loading, responsive, and touch-friendly.

## Capabilities and Constraints

- Centralized config (`src/profileConfig.js`) for profile data and social links.
- Verified links for Facebook, TikTok, Gmail, and GitHub.
- Obsidian dark theme (#09090b/#030712) with subtle violet aura/glows (#8b5cf6 / #a855f7).
- Responsive, accessible contrast, smooth entry animations.

## Brand Commitments

Modern minimalist, deep black/white palette with subtle violet ambient lighting and subtle glassmorphism borders.

## Evidence on Hand

Clean greenfield project. User-requested social channels: Facebook, TikTok, Gmail, GitHub.

## Product Principles

- Restraint over clutter: High signal-to-noise ratio.
- Micro-interaction polish: Delightful hover/press states with soft violet radiance.
- Effortless maintenance: 1-file content updates.
